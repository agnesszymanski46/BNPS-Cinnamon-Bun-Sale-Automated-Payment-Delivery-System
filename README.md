BNPS Cinnamon Bun Sale – Payment Tracker
An automated payment processing system for fundraising campaigns

📋 Project Overview
This dual-platform solution automates payment tracking from Venmo, PayPal, and Zelle by scanning email notifications and extracting transaction data into organized spreadsheets. Built with VBA (Excel) and Google Apps Script.

🚀 Getting Started
Choose your preferred platform:
Option 1: Google Sheets (Recommended)
Best for: Browser-based access, Gmail users
👉 Open Google Sheet
Setup Instructions:
Click the link above to view the tracker
Go to File → Make a copy to create your own version
Refresh the page after copying (close and reopen)
Click "NPS Tools" in the menu bar → Select "Check Venmo Payments"
When prompted, click "Continue" → "Advanced" → "Go to NPS Cinnamon Bun Sale Tracker (unsafe)" → "Allow"
The script will now scan your Gmail for payment notifications
Note: The "unsafe" warning is standard for personal Google Apps Scripts. Your data remains private and is only accessible in your Google account.

Option 2: Excel with VBA
Best for: Desktop users, Outlook email
👉 Download Excel File (.xlsm)
Setup Instructions:
Download the .xlsm file using the link above
Locate the file in your Downloads folder
Right-click the file → Properties → Check "Unblock" at the bottom → Click OK
Open the file in Excel desktop (not Excel Online)
Click "Enable Content" in the security warning banner at the top
Use the dashboard buttons to scan Outlook for payments
Security Note: This file contains VBA macros that read payment notification emails from Outlook. The code is read-only and does not modify system files. You can review the source code by pressing Alt+F11 in Excel.

🔧 Features
Automated email parsing for Venmo, PayPal, and Zelle notifications
Duplicate detection to prevent double-counting
Smart quantity calculation based on payment amounts
Real-time dashboard with total counts and status tracking
Cross-platform compatibility (Google Sheets & Excel)

💡 Technical Details
Technologies Used:
Google Apps Script (JavaScript-based)
VBA (Visual Basic for Applications)
Regular expressions for email parsing
OAuth 2.0 for Gmail API access

View Source Code:
Google Apps Script: Extensions → Apps Script (in the Google Sheet)
Excel VBA: Press Alt+F11 in Excel to view code

🛠️ Troubleshooting
Google Sheets:
Menu not appearing? Refresh the page or go to Extensions → Apps Script → Click Run (▶️)
No emails found? Verify you authorized the correct Gmail account that receives payment notifications
Excel:
Macros disabled? Make sure you clicked "Enable Content" and unblocked the file properties
Outlook not installed? The Excel version requires Outlook desktop to be installed and configured
